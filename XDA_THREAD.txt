[SIZE="5"][B][COLOR="#0099CC"]What is AROMA-Next-Installer?[/COLOR][/B][/SIZE]
[B]AROMA-Next-Installer[/B] is a modern `arm64-v8a` + `armeabi-v7a` revival of Ahmad Amarullah's classic [B]AROMA Installer[/B] (Apache 2.0), rebuilt for Android 10–16+ devices, modern custom recoveries ([B]TWRP[/B], [B]OrangeFox[/B], [B]AERA Recovery[/B], [B]PitchBlack[/B]), and safe [B][COLOR="#00AA55"]Systemless-First[/COLOR][/B] modding ([B]Magisk[/B], [B]KernelSU[/B], [B]APatch[/B]).

[SIZE="4"][B][COLOR="#0099CC"]Highlights[/COLOR][/B][/SIZE]
[LIST]
[*][B][COLOR="#0099CC"]60–120Hz+ DRM/KMS Engine & Smooth Transitions:[/COLOR][/B] Pure Linux kernel ioctl [B]Atomic KMS[/B] double-buffered engine (zero `libdrm.so` dependency) with direct single-pass ARM NEON backbuffer blitting, Exynos/Tensor & [B]Qualcomm `msm_drm` Dual-LM Source-Split (AERA Recovery)[/B] support, plus 5 VSYNC-locked transitions ([B]Fade[/B] Default, [B]Slide[/B], [B]Stack[/B], [B]Zoom[/B], [B]None[/B]).
[*][B][COLOR="#9B59B6"]Google Sans Default + 7 Modern Open-Source Fonts:[/COLOR][/B] Ships with official [B]Google Sans[/B] (SIL OFL) by default alongside [I]Roboto, Inter, Plus Jakarta Sans, Outfit, Ubuntu, JetBrains Mono[/I], and full Latin/Cyrillic/Hebrew/CJK UTF-8 fallback.
[*][B][COLOR="#9B59B6"]Streamlined 3-Dot Menu & Themes Hub:[/COLOR][/B] Clean top-to-bottom menu ([B]About → Themes → Filemanager → Exit → Back[/B]). Tap [B]Themes[/B] at any step to switch [B]Themes[/B] ([I]Black & White, ICS, MIUI 4, MIUI, Touchwiz, Franzyroy, Generic[/I]), [B]Fonts[/B], or [B]Transitions[/B] live without restarting or losing selections.
[*][B][COLOR="#00AA55"]Integrated AROMA-Next-Filemanager & Root Module Manager:[/COLOR][/B] Built directly into the shared binary ([B]3-Dot Menu → Filemanager[/B] or standalone `AROMA-Next-Filemanager.zip`) with 4 inline tabs ([B]Modules | Storage | System | Tools[/B]):
  [LIST]
  [*][B]Modules (`/data/adb/modules`):[/B] Enable/disable Magisk/KSU/APatch modules, mark for removal, delete, browse files, and edit `module.prop` / `system.prop`.
  [*][B]Storage & System:[/B] Full `/sdcard` & system partition browsing with live `[RW]`/`[RO]` detection, safe [B]Remount Partition RW[/B], Copy/Cut/Paste/Delete/Rename/`chmod`, built-in [B]Touch QWERTY Keyboard[/B], and [B]Text Viewer & Line Editor[/B].
  [/LIST]
[*][B][COLOR="#0099CC"]Modern HiDPI Splash & Nostalgia Animation:[/COLOR][/B] Crisp 920×360 HiDPI [B]AROMA-Next-Installer[/B] Google Sans splash screen with the classic AROMA echo-pulse animation & automatic proportional HiDPI scaling.
[*][B][COLOR="#0099CC"]Modernized 2026 Core Libraries:[/COLOR][/B] Upgraded all vendored libraries to [B]`zlib 1.4`[/B], [B]`libpng 1.6.59`[/B] (ARM NEON intrinsics), [B]`FreeType 2.15.0`[/B] (LCD Subpixel + Variable Fonts), and RFC 3629-compliant [B]`minutf8`[/B].
[*][B][COLOR="#00AA55"]Safe by Design (Zero Recovery Hangs):[/COLOR][/B] Cleanly pauses/resumes recovery and restores all DRM planes on exit; exits safely with code `77` (`AROMA_EXIT_NO_DISPLAY`) with non-GUI fallback if a recovery holds an unshared display lock.
[*][B][COLOR="#E67E22"]Flash Anywhere (Recovery OR Root App):[/COLOR][/B] Full Touch GUI inside custom recoveries (`BOOTMODE=false`) and automatic headless module installation inside the Magisk / KernelSU / APatch app (`BOOTMODE=true`).
[*][B][COLOR="#0099CC"]High-Hz OLED Touch & Screenshot Combo:[/COLOR][/B] Scans `/dev/input/event0..63`, supports Multitouch Type-B (`ABS_MT_SLOT`), and cleanly captures `.bmp` screenshots via [B]Vol-Down + Power[/B] with shutter flash.
[/LIST]

[SIZE="5"][B][COLOR="#E67E22"]Developer & Module Author Corner[/COLOR][/B][/SIZE]
[COLOR="#7F8C8D"]Everything below is intended for ROM builders, kernel devs, and Magisk / KernelSU / APatch module authors integrating AROMA-Next into their own ZIPs.[/COLOR]

[HIDE="Click to expand Developer Guide, Systemless API, Architecture & Build Instructions"]
[SIZE="4"][B][COLOR="#0099CC"]1. Dual-Mode Systemless & Optional Pre-RW Template (`magisk-template/`)[/COLOR][/B][/SIZE]
Modern Android (`/system`, `/vendor`, `/product`, `/system_ext`) uses read-only [B]EROFS[/B] or deduplicated `shared_blocks` `ext4` with `dm-verity`. `AROMA-Next-Magisk-Template.zip` solves this cleanly:
[LIST]
[*][B][COLOR="#00AA55"]Systemless Mode (Default):[/COLOR][/B] Outputs a standard Magisk / KernelSU / APatch overlay module (`$MODPATH`, or directly `/data/adb/modules/<id>` via the built-in standalone recovery installer). Works on EROFS & active `dm-verity` with zero bootloop risk.
[*][B][COLOR="#E67E22"]Direct RW Mode (Optional):[/COLOR][/B] For partitions pre-converted with `RO2RW` / `SystemRW` and rebooted beforehand (`aroma_probe_rw()` checks real writability first and falls back to Systemless if read-only).
[/LIST]

[B]Helper API (`aroma-mod-lib.sh`) for `customize.sh`:[/B]
[CODE]aroma_mod_init "$REQ_MODE" "$MODPATH" 1
aroma_mod_edit_prop "ro.config.media_vol_steps" "30"
aroma_mod_copy "$MODPATH/files/my.conf" "system/etc/my.conf" 0644
aroma_mod_delete "system/app/ExampleBloat" "dir"
aroma_mod_patch_file "system/etc/hosts" "s/old_entry/new/"[/CODE]

[B]Launching Filemanager from any `aroma-config`:[/B]
[CODE]filemanager();                   # Opens Modules / Storage view
filemanager("/data/adb/modules"); # Opens specific start directory[/CODE]

[SIZE="4"][B][COLOR="#0099CC"]2. Under-the-Hood Engine Modernization[/COLOR][/B][/SIZE]
[LIST]
[*][B]64-bit & C11 Cleanliness:[/B] Replaced 32-bit pointer truncations (`uintptr_t`/`intptr_t`), fixed `AARRAY_ITEM` sizing, `0755` permissions, `ag_draw_strecth_ex` bounds clipping, C11 inline linkage, and ARM64 NEON blitter alpha init.
[*][B]DRM/KMS Atomic Engine (`src/libs/graph_drm.c`):[/B] Zero `libdrm.so` dependency; inherits DRM master FDs via `/proc/self/fd`, drives Atomic KMS double-buffered dumb buffers with direct single-pass NEON blitting, handles Exynos/Tensor `RGBA8888` & Qualcomm `msm_drm` Dual-LM Source-Split, restores all recovery planes before `RMFB`, and falls back to `SETCRTC` + `DIRTYFB` / `fbdev`.
[*][B]Vendored Libraries (2026):[/B] `zlib 1.4`, `libpng 1.6.59` (ARM NEON), `FreeType 2.15.0`, RFC 3629 `minutf8`.
[*][B]Input & Recovery Safety:[/B] `INDR_MAXDEV = 64`, Multitouch Type-B `ABS_MT_SLOT`, LED vibrator fallback, ancestor `SIGSTOP`/`SIGCONT` chain, high-FD `/proc/self/fd/$OUTFD` pipe handling, and `EXIT 77` non-GUI fallback.
[/LIST]

ndk-build NDK_PROJECT_PATH=. APP_BUILD_SCRIPT=Android.mk NDK_APPLICATION_MK=Application.mk -j4

# Cross-compiling static binaries + all 4 ZIPs via Zig:
python build.py --arch arm64 arm32[/CODE]
