[SIZE=5][B][COLOR=#0099CC]What are ANI & ANF?[/COLOR][/B][/SIZE]
[LIST]
[*][B][COLOR=#0099CC]ANI[/COLOR] = AROMA-Next-Installer:[/B] The modern [ICODE]arm64-v8a[/ICODE] + [ICODE]armeabi-v7a[/ICODE] revival of Ahmad Amarullah's classic [B]AROMA Installer[/B] (Apache 2.0), rebuilt for Android 10–17+ devices, custom recoveries ([B]TWRP[/B], [B]OrangeFox[/B], [B]AERA Recovery[/B], [B]PitchBlack[/B]), custom kernels ([URL=https://github.com/Miustone/AROMA-Next-AnyKernel3]AROMA-Next-AnyKernel3[/URL]), and safe [B][COLOR=#00AA55]Systemless-First[/COLOR][/B] modding ([B]Magisk[/B], [B]KernelSU[/B], [B]APatch[/B]).
[*][B][COLOR=#00AA55]ANF[/COLOR] = AROMA-Next-Filemanager:[/B] The built-in 4-tab recovery file manager, root module manager, Bootloop-Saver, ZIP Inspector, Quick Reboot & Diagnostics toolkit — available both via [B]3-Dot → Filemanager[/B] inside every ANI installer AND as a standalone [ICODE]AROMA-Next-Filemanager.zip[/ICODE].
[/LIST]

[SIZE=4][B][COLOR=#0099CC]1. Dual-Mode Systemless & Optional Pre-RW Template ([ICODE]magisk-template/[/ICODE])[/COLOR][/B][/SIZE]
Modern Android ([ICODE]/system[/ICODE], [ICODE]/vendor[/ICODE], [ICODE]/product[/ICODE], [ICODE]/system_ext[/ICODE]) uses read-only [B]EROFS[/B] or deduplicated [ICODE]shared_blocks[/ICODE] [ICODE]ext4[/ICODE] with [ICODE]dm-verity[/ICODE]. [ICODE]AROMA-Next-Magisk-Template.zip[/ICODE] solves this cleanly:
[LIST]
[*][B][COLOR=#00AA55]Systemless Mode (Default):[/COLOR][/B] Outputs a standard Magisk / KernelSU / APatch overlay module ([ICODE]$MODPATH[/ICODE], or directly [ICODE]/data/adb/modules/<id>[/ICODE] via the built-in standalone recovery installer). Works on EROFS & active [ICODE]dm-verity[/ICODE] with zero bootloop risk.
[*][B][COLOR=#E67E22]Direct RW Mode (Optional):[/COLOR][/B] For partitions pre-converted with [ICODE]RO2RW[/ICODE] / [ICODE]SystemRW[/ICODE] and rebooted beforehand ([ICODE]aroma_probe_rw()[/ICODE] checks real writability first and falls back to Systemless if read-only).
[/LIST]

[B]Helper API ([ICODE]aroma-mod-lib.sh[/ICODE]) for [ICODE]customize.sh[/ICODE]:[/B]
[CODE]aroma_run_config_if_needed   # Auto-runs Volume Key Selector from aroma-config in BOOTMODE=1!
aroma_mod_init "$REQ_MODE" "$MODPATH" 1
aroma_mod_edit_prop "ro.config.media_vol_steps" "30"
aroma_mod_copy "$MODPATH/files/my.conf" "system/etc/my.conf" 0644
aroma_mod_delete "system/app/ExampleBloat" "dir"
aroma_mod_patch_file "system/etc/hosts" "s/old_entry/new/"[/CODE]

[B]Launching ANF (Filemanager) from any [ICODE]aroma-config[/ICODE]:[/B]
[CODE]filemanager();                   # Opens Modules / Storage view
filemanager("/data/adb/modules"); # Opens specific start directory[/CODE]

[B]Automatic CI Packaging with Reusable GitHub Action ([URL=https://github.com/Miustone/aroma-next-action]Miustone/aroma-next-action@v1[/URL]):[/B]
Package your module, AnyKernel3 kernel, or ROM with official ANI binaries automatically in GitHub Actions without committing binaries into your repo!
[CODE]- uses: Miustone/aroma-next-action@v1
  with:
    source_dir: .
    template: magisk          # magisk | anykernel3 | installer | none
    aroma_version: latest
    architectures: arm64,arm32
    output_zip: dist/MyModule-AROMA.zip
    github_token: ${{ secrets.GITHUB_TOKEN }}[/CODE]

[SIZE=4][B][COLOR=#0099CC]2. Under-the-Hood Engine Modernization[/COLOR][/B][/SIZE]
[LIST]
[*][B]64-bit & C11 Cleanliness:[/B] Replaced 32-bit pointer truncations ([ICODE]uintptr_t[/ICODE]/[ICODE]intptr_t[/ICODE]), fixed [ICODE]AARRAY_ITEM[/ICODE] sizing, [ICODE]0755[/ICODE] permissions, [ICODE]ag_draw_strecth_ex[/ICODE] bounds clipping, C11 inline linkage, and ARM64 NEON blitter alpha init.
[*][B]DRM/KMS Atomic Engine ([ICODE]src/libs/graph_drm.c[/ICODE]):[/B] Zero [ICODE]libdrm.so[/ICODE] dependency; inherits DRM master FDs via [ICODE]/proc/self/fd[/ICODE], drives Atomic KMS double-buffered dumb buffers with direct single-pass NEON blitting, handles Exynos/Tensor [ICODE]RGBA8888[/ICODE] & Qualcomm [ICODE]msm_drm[/ICODE] Dual-LM Source-Split, restores all recovery planes before [ICODE]RMFB[/ICODE], and falls back to [ICODE]SETCRTC[/ICODE] + [ICODE]DIRTYFB[/ICODE] / [ICODE]fbdev[/ICODE].
[*][B]Vendored Libraries (2026):[/B] [ICODE]zlib 1.4[/ICODE], [ICODE]libpng 1.6.59[/ICODE] (ARM NEON), [ICODE]FreeType 2.15.0[/ICODE], RFC 3629 [ICODE]minutf8[/ICODE].
[*][B]Input & Recovery Safety:[/B] [ICODE]INDR_MAXDEV = 64[/ICODE], Multitouch Type-B [ICODE]ABS_MT_SLOT[/ICODE], LED vibrator fallback, ancestor [ICODE]SIGSTOP[/ICODE]/[ICODE]SIGCONT[/ICODE] chain, high-FD [ICODE]/proc/self/fd/$OUTFD[/ICODE] pipe handling, and [ICODE]EXIT 77[/ICODE] non-GUI fallback.
[/LIST]
