AROMA-Next-Installer (ANI) Changelog
====================================

V26.11-RC5 (NextGen)
--------------------
- New AMOLED Modern Material 3 You default theme (Monochrome White default
  + 8 Live Accent Colors & #RRGGBB hex support) across ANI & ANF
- Unified Material 3 rounded cards across viewbox, menubox, selectbox,
  checkbox, form, textbox, slider, dialogs, bottom sheets & bottom nav bar
- 17 redesigned 4x-supersampled Material 3 You icons (all 7 classic themes
  remain 100% preserved)
- 1-Tap Stay-Open Live Appearance Hub (3-dot -> Appearance & live_appearance)
- Punch-hole-safe Android Top Status Bar (clock + active A/B slot + battery)
- Lossless PNG screenshots via libpng 1.6.59 (~250 KB instead of 9 MB BMP)
- New interactive slider(...) Edify control (Touch drag + VolKey stepper)
- Upgraded ANF (AROMA-Next-Filemanager) Toolkit: Bootloop-Saver (Disable/
  Re-Enable ALL Modules), ZIP Inspector & Extractor, Quick Reboot Menu,
  /tmp/recovery.log backup & Hardware Diagnostics export
- Upgraded BOOTMODE=1 VolKey Selector: Go Back + VOL- long-press + --preset
- Fixed Linux MT Type-B touch scrolling & mutex touch FIFO queue, CRLF
  Edify stripping, and 2048B About/Alert/Confirm dialog text buffers
- New companion repos: AROMA-Next-AnyKernel3 & Miustone/aroma-next-action@v1

V26.11-RC4 (NextGen)
--------------------
- New default font: Google Sans (official Android static TTF, SIL OFL)
- 7 bundled modern open-source fonts: Google Sans, Roboto, Inter,
  Plus Jakarta Sans, Outfit, Ubuntu, JetBrains Mono + CJK fallback
- Streamlined 3-dot menu (About, Themes, Filemanager, Exit, Back) with
  dedicated Themes submenu for Select Theme, Select Font & Transitions
- 5 smooth 60-120Hz VSYNC Transitions: Slide, Stack, Fade, Zoom & None
- Integrated AROMA-Next-Filemanager & Root Module Manager:
  * Accessible from the 3-dot menu inside any installer AND as standalone
    AROMA-Next-Filemanager.zip
  * Inline Modules / Storage / System / Tools tabs with active tab highlight
  * Manage /data/adb/modules (Magisk / KernelSU / APatch): Enable, Disable,
    Mark for Removal, Delete, Browse files, Edit module.prop & system.prop
  * Full /sdcard & System partition management with live [RW]/[RO] status,
    safe Remount RW, built-in Touch Keyboard, and Text Viewer & Line Editor
- Modernized HiDPI "AROMA-Next-Installer" splash screen with classic
  nostalgia echo animation & automatic HiDPI scaling
- Clean Base Installer ZIP separated from full interactive AROMA-Next-Demo.zip

V26.11-RC3
----------
- Upgraded core libraries: zlib 1.4, libpng 1.6.59 (ARM NEON intrinsics),
  FreeType 2.15.0, RFC 3629 strict UTF-8 decoder (minutf8)
- Direct DRM backbuffer NEON blitting & smooth 60-120Hz VSYNC-locked
  time-based animations
- Theme dialog Back (left) / OK (right) button alignment fix

V26.11-RC2
----------
- Black & White default theme by Miustone
- Runtime theme switcher in the 3-dot menu
- Universal arm64-v8a & armeabi-v7a static musl recovery binaries
- Magisk / KernelSU / APatch recovery module installer template

V26.11-RC1
----------
- Initial 64-bit DRM/KMS & modern multi-touch modernization of AROMA Installer
  for Android 13-16+ devices and modern custom recoveries (TWRP, OrangeFox, AERA)
